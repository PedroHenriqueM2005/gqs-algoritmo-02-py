Programa em Python, feito para ajudar no calculo de produtos e controle em compras.

- calculo individual de descontos e valores de produtos
- soma total dos valores
- verificação de estimativa de gastos

## como executar:

clonar o repositorio:

git clone https://github.com/PedroHenriqueM2005/gqs-algoritmo-02-py
cd gqs-algoritmo-02-py
python src/calculadora_descontos.py

Copie o conteúdo do arquivo `calculadora_descontos.py` (dentro da pasta `src/`)


### Salve o arquivo com extensão `.py`

Se você copiou o código manualmente, salve com o nome, por exemplo:


calculadora_descontos.py


> É importante que o arquivo termine com **.py**, pois é essa extensão
> que o computador usa para reconhecer que é um código Python.

### Abra o arquivo no VSCode

- Abra o **Visual Studio Code**
- Vá em **File > Open File** e selecione o arquivo `calculadora_descontos.py`

### Execute o programa


**Opção A — Botão Play **
- No canto superior direito da tela do VSCode, clique no botão em forma de (PlAY)
- O terminal abrirá automaticamente e o programa vai iniciar

Opção B — Terminal manuaAL
- Abra o terminal do VSCode (`Terminal > New Terminal`)
- Digite o comando:

python calculadora_descontos.py



### Use o programa

O terminal vai pedir para você digitar:

- teto de gastos que você quer controlar
1. Nome do produto
2. Valor do produto
3. Percentual de desconto
4. (repete até você apertar **Enter** sem digitar nada) o que encerra a lista

No final, ele mostra um **relatório completo** com todos os valores e um alerta se o gasto passou do limite. 🎉



- Ter o **Python 3.8 ou superior** instalado no computador
  - Verifique com: `python --version` ou `python3 --version`
  - Se não tiver instalado, baixe em: https://www.python.org/downloads/
- Ter o **VSCode** instalado (opcional, mas recomendado)
  - Baixe em: https://code.visualstudio.com/
  - Instale a extensão **Python** (da Microsoft) dentro do VSCode
